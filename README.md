# Telegram — коннектор для Claude

Локальный MCP-сервер, через который Claude работает с Telegram **от имени вашего аккаунта** — как юзербот, через тот же протокол MTProto, что и официальные приложения. Это не бот: Claude видит ваши чаты, пишет от вашего имени, вступает в группы, нажимает кнопки ботов.

Коннектор ставится в Claude Desktop как расширение (`.mcpb`). Всё, что Claude разрешено делать, настраивается в окне установки расширения и потом в его настройках.

## Что умеет

- **Чаты.** Список чатов с непрочитанными, упоминаниями, папками и архивом; подробности о пользователе, боте, группе или канале (описание, участники, права, закреп, команды бота, темы форума); просмотр приглашения без вступления.
- **Сообщения.** Чтение истории, веток и комментариев к постам, конкретных сообщений по ссылке; поиск по чату и по всем чатам с фильтрами (фото, ссылки, голосовые, упоминания, даты, отправитель); ожидание новых сообщений.
- **Отправка.** Сообщения с форматированием, ответы с цитатой, отложенная отправка, темы форумов; правка, пересылка (в том числе без автора), реакции, закрепление, голосование в опросах, отметка «прочитано».
- **Файлы.** Отправка фото, видео, документов, голосовых, кружков и альбомов — из разрешённых папок или по ссылке. Фотографии из чатов Claude видит прямо в ответе, документы и видео сохраняются на диск; небольшие текстовые файлы читает сразу.
- **Голосовые в текст.** Расшифровка голосовых, кружков, аудио и видео через Groq, OpenAI или свой сервер Whisper — сам Telegram расшифровывает их только с Premium.
- **Боты.** Нажатие кнопок под сообщениями и на клавиатурах ботов с ответом бота и обновлённым сообщением, `/start` с параметром из ссылки, inline-запросы (`@gif котики`).
- **Поиск и вступление.** Поиск людей, ботов, групп и каналов по имени и @username, вступление по @username и ссылкам-приглашениям (с заявкой, если нужна).
- **Администрирование** (выключено по умолчанию). Бан, ограничения, админы, название, описание, фото, медленный режим, приглашения, ссылки, заявки на вступление, создание групп и каналов.
- **Профиль и контакты** (выключено по умолчанию). Имя, био, @username, фото; добавление, удаление и блокировка контактов.
- **Прямые вызовы Telegram API** (выключено по умолчанию) — для всего остального, со справкой по схеме API.
- **Несколько аккаунтов.** Аккаунт по умолчанию, выбор аккаунта в разговоре, аккаунты «только для чтения».

## Безопасность

### Разрешения

Каждая группа действий включается отдельным переключателем. Выключенные инструменты Claude не видит вовсе, а если попробует их вызвать — получит отказ с названием настройки.

| Настройка | Что разрешает | По умолчанию |
|---|---|---|
| — | чтение чатов, сообщений, участников, контактов; поиск; скачивание вложений | всегда |
| Разрешить отправку сообщений | отправка, ответы, правка, пересылка, реакции, закрепление, опросы, «прочитано», файлы | вкл. |
| Разрешить работу с ботами | кнопки, `/start`, inline-запросы | вкл. |
| Разрешить вступать в чаты | вступление в группы и каналы | вкл. |
| Разрешить удаление и выход из чатов | удаление сообщений, выход из групп и каналов, удаление личных чатов | выкл. |
| Разрешить администрирование чатов | управление участниками и чатами, создание групп и каналов | выкл. |
| Разрешить менять профиль и контакты | свой профиль, контакты, отправка своего номера боту по его кнопке | выкл. |
| Разрешить прямые вызовы Telegram API | любые методы MTProto, в обход остальных ограничений коннектора | выкл. |

Дополнительно:

- **Скрытые чаты** — их Claude не видит нигде: ни в списке чатов, ни в поиске, ни по ссылке.
- **Только эти чаты** — если заполнено, Claude видит только перечисленные чаты.
- **Писать только в эти чаты** — отправка, реакции и кнопки только здесь; читать можно всё видимое.
- **Аккаунты только для чтения** — с этими аккаунтами доступно только чтение, даже если действия разрешены.
- **Папки для отправки файлов** — Claude отправляет только файлы из этих папок. Скрытые файлы и папки (`.ssh`, `.env` и т. п.) и папка с сессиями коннектора не отправляются никогда, символические ссылки наружу не помогают. Файлы по ссылке скачивает сам Telegram — коннектор чужие адреса не открывает.
- **Лимит действий в минуту** (по умолчанию 20 на аккаунт) — защита от антиспама Telegram, если Claude увлечётся.

Чаты в списках задаются через запятую: `@username`, ссылкой `t.me/…` (подойдёт и ссылка на сообщение закрытого канала `t.me/c/…`, и приглашение `t.me/+…`), числовым id (`-1001234567890` — такие id показывает сам коннектор) или словом `me` («Избранное»). Нераспознанные записи видны в `connector_status`.

Про приглашения `t.me/+…`: сама ссылка из «Скрытых чатов» закрыта всегда, а чтобы узнавать чат и по id, коннектор спрашивает у Telegram, какой чат за ней стоит. Это возможно, только когда аккаунт уже в чате: пока он не вступил, ссылка значится в `connector_status` как не опознанная и проверяется снова при загрузке списка чатов и не реже раза в минуту. Надёжнее указывать `@username` или id.

### Что закрыто всегда

- **Служебный чат Telegram (777000)** — туда приходят коды входа. Коннектор его не показывает и не читает: ни в списках и поиске, ни по номеру сообщения, ни через прямые вызовы API (такие сообщения вырезаются из ответов).
- **Деньги.** Платные сообщения и реакции, кнопки оплаты, Telegram Stars, платежи, подарки и ставки — ни через инструменты, ни через прямые вызовы API. Если собеседник берёт Stars за сообщение, отправка вернёт отказ.
- **Вход и безопасность аккаунта.** Подтверждение чужого входа (QR с другого устройства), завершение сессий, смена пароля, почты и номера, ключи доступа (passkeys), push-устройства, подключённые бизнес-боты, самоуничтожение и удаление аккаунта, передача прав владельца, Telegram Passport, всё, что требует облачного пароля, — закрыто, в том числе для прямых вызовов API.
- **Вход на сайты через Telegram и мини-приложения** — кнопки таких типов не нажимаются, Claude получает только ссылку.

Прямые вызовы API обходят остальные ограничения коннектора, но не эти. Кроме того:

- методы удаления, очистки и выхода работают, только если включено и «Разрешить удаление и выход из чатов»;
- скрытые чаты остаются скрытыми: чаты в параметрах (в том числе объектом или числом `chat_id`) сверяются со списками, а из ответа вырезается всё, что относится к закрытым чатам, — сообщения, диалоги, обновления, контакты, записи пользователей и чатов. Автор сообщения в видимой группе остаётся, если он сам не в «Скрытых чатах». При заполненном «Только эти чаты» незнакомый коннектору id закрыт;
- методы, которые по номерам сообщений без указания чата могли бы задеть скрытые чаты (`messages.deleteMessages`, `messages.forwardMessages`, `messages.readMessageContents`), недоступны — для этого есть свои инструменты; служебные методы MTProto и выгрузка всех контактов разом тоже закрыты.

### Вход в аккаунт

Коды и облачный пароль вводятся **на локальной странице** в браузере (или в терминале), а не в чате: они уходят прямо в Telegram, Claude их не видит, коннектор их не хранит. Страница открывается только на этом компьютере (`127.0.0.1`), защищена случайным токеном в адресе, проверкой Host и Origin и строгим CSP, и сама закрывается через 30 минут без действий.

Сессии хранятся в `~/.telegram-mcp/accounts/<имя>.json` с правами `0600` (папка — `0700`). Файл сессии равен доступу к аккаунту: не передавайте его никому. В Telegram (Настройки → Устройства) сессия видна как устройство **Claude**, а в строке приложения — название приложения с my.telegram.org и слово Connector (если приложение названо «Claude» — **Claude Connector**). Завершить сессию оттуда можно в любой момент.

### Содержимое чатов — чужие данные

Тексты сообщений, имена, описания, подписи кнопок и ответы ботов пишут другие люди. Коннектор прямо говорит Claude считать их данными, а не инструкциями, и не выполнять просьбы из сообщений без вашего подтверждения. Инструменты чтения помечены как безопасные: в Claude Desktop их можно разрешить навсегда, а отправку, кнопки и удаление подтверждать каждый раз.

Telegram разрешает юзерботов, но наказывает за спам: массовые сообщения незнакомым людям и частые вступления могут ограничить аккаунт (`PEER_FLOOD`). Не просите Claude рассылать сообщения.

## Установка

1. **API ID и API Hash.** Откройте [my.telegram.org](https://my.telegram.org) → API development tools, создайте приложение (название любое) и скопируйте `api_id` и `api_hash`. Это ключ вашего «приложения» — один на все ваши аккаунты.
2. **Пакет.** Соберите его (нужен Node.js 20+):

   ```bash
   npm ci && npm run pack
   ```

   Получится `dist/telegram.mcpb`.
3. **Установка.** Откройте `dist/telegram.mcpb` двойным щелчком (или перетащите в Claude Desktop → Настройки → Расширения). Claude Desktop покажет окно установки с настройками.
4. **Настройки.** Обязательны только API ID и API Hash, остальное можно оставить как есть:

| Поле | Зачем |
|---|---|
| API ID, API Hash | с my.telegram.org; API Hash хранится в защищённом хранилище системы |
| Аккаунт по умолчанию | имя или @username аккаунта, с которым работать, если их несколько |
| Разрешить … | переключатели из таблицы выше |
| Только эти чаты / Скрытые чаты / Писать только в эти чаты | ограничения по чатам |
| Аккаунты только для чтения | имена аккаунтов через запятую |
| Папки для отправки файлов | по умолчанию Загрузки, Рабочий стол, Изображения |
| Папка для скачанных файлов | по умолчанию Загрузки |
| Лимит действий в минуту | по умолчанию 20 |
| Ключ API для расшифровки голосовых | ключ Groq или OpenAI — см. [Расшифровка голосовых](#расшифровка-голосовых); хранится в защищённом хранилище системы |
| Адрес API для расшифровки, Модель для расшифровки | необязательно: свой сервер Whisper или другая модель |
| Прокси | `socks5://user:pass@host:port`, `socks4://host:port` или ссылка MTProxy `tg://proxy?server=…&port=…&secret=…` |

5. **Вход.** Напишите Claude: «Подключи мой Telegram». Он вызовет `open_login_page`, в браузере откроется страница входа — по QR-коду (Telegram на телефоне → Настройки → Устройства → Подключить устройство) или по номеру телефона и коду. Если включена двухэтапная аутентификация, страница спросит облачный пароль.

Изменить настройки потом: Claude Desktop → Настройки → Расширения → Telegram → Настроить. После сохранения расширение перезапускается с новыми разрешениями.

Обновление: откройте новый `telegram.mcpb` так же, как при установке. Настройки, ключи и вход в аккаунты сохраняются: расширение узнаётся по имени и автору, а сессии лежат в `~/.telegram-mcp`.

Проверка: попросите Claude вызвать `connector_status` с `check: true` — он покажет подключённые аккаунты, включённые разрешения и проблемы в настройках.

### Вход из терминала

Если удобнее терминал (например, для Claude Code):

```bash
TELEGRAM_API_ID=123456 TELEGRAM_API_HASH=… node server/cli.js login --account work
```

Команды: `login [--account имя] [--qr | --phone +7…]`, `list`, `logout <имя>`, `import <имя>` — принять готовую строку сессии GramJS, Telethon или teleproto. API ID и API Hash можно не задавать в окружении — CLI спросит.

## Несколько аккаунтов

У каждого аккаунта есть имя: вы задаёте его при входе, иначе берётся @username. Claude работает с аккаунтом по умолчанию (настройка «Аккаунт по умолчанию»; если аккаунт один — с ним), а с другими — когда вы попросите: «напиши с рабочего аккаунта». Если аккаунтов несколько и по умолчанию не выбран ни один, Claude спросит, от чьего имени действовать.

Повторный вход в тот же аккаунт обновляет его сессию. Если имя уже занято другим аккаунтом, новый сохранится под другим именем — чужая сессия не затрётся.

## Расшифровка голосовых

Claude не слышит звук, а сам Telegram расшифровывает голосовые только с Premium. Поэтому `transcribe_voice` отправляет звук в сервис распознавания речи с API, совместимым с OpenAI, и возвращает текст. Подходят голосовые, кружки, аудио и видео до 25 МБ; до 10 сообщений за вызов.

- **Groq** — бесплатно и быстро, модель `whisper-large-v3-turbo`. Ключ (`gsk_…`) создаётся на [console.groq.com/keys](https://console.groq.com/keys).
- **OpenAI** — платно, модель `gpt-4o-mini-transcribe`. Ключ `sk-…` — на [platform.openai.com/api-keys](https://platform.openai.com/api-keys).
- **Свой сервер** — например, `whisper.cpp` (`whisper-server`) или [speaches](https://github.com/speaches-ai/speaches) на этом компьютере: укажите «Адрес API для расшифровки» (`http://127.0.0.1:8000/v1`), ключ тогда не нужен, а звук не покидает компьютер. По http — только к серверу на этом компьютере или в локальной сети.

Сервис определяется по виду ключа; «Адрес API» и «Модель» нужны, только чтобы выбрать другой. Звук уходит в сервис, только когда Claude расшифровывает конкретное сообщение; расшифровки запоминаются до перезапуска расширения, повторно звук не отправляется. Какой сервис включён, видно в `connector_status`.

## Инструменты

Названия — действия без приставки `telegram_`, как у коннектора Bybit: Claude подписывает вызов инструмента локального расширения его названием («send_message» → «Send message»), а название коннектора и значок и так стоят рядом.

| Инструмент | Разрешение | Что делает |
|---|---|---|
| `connector_status` | всегда | аккаунты, разрешения, ограничения; `check` — проверка сессий |
| `open_login_page` | всегда | страница входа и выхода |
| `list_chats` | чтение | список чатов: непрочитанные, тип, поиск по названию, папка, архив |
| `list_chat_folders` | чтение | папки чатов |
| `get_chat_info` | чтение | сведения о чате или пользователе, просмотр приглашения |
| `search_chats` | чтение | поиск людей, ботов, групп и каналов |
| `get_chat_members` | чтение | участники и их роли |
| `list_contacts` | чтение | контакты (телефоны — только по запросу) |
| `get_messages` | чтение | история, ветки, комментарии, сообщения по id, ожидание новых |
| `search_messages` | чтение | поиск по чату или по всем чатам |
| `download_media` | чтение | фото в ответе, файлы на диск, аватары |
| `transcribe_voice` | чтение | расшифровка голосовых, кружков, аудио и видео в текст |
| `send_message` | отправка | сообщение, ответ, отложенная отправка |
| `send_file` | отправка | фото, видео, документы, голосовые, альбомы |
| `edit_message` | отправка | правка своего сообщения |
| `forward_messages` | отправка | пересылка, в том числе без автора |
| `react_to_message` | отправка | реакция |
| `mark_as_read` | отправка | отметить прочитанным |
| `pin_message` | отправка | закрепить, открепить |
| `vote_in_poll` | отправка | голос в опросе |
| `press_button` | боты | нажатие кнопки |
| `start_bot` | боты | `/start`, в том числе с параметром |
| `get_inline_results` | боты | inline-запрос |
| `send_inline_result` | боты + отправка | отправка результата inline-запроса |
| `join_chat` | вступление | вступление по @username или приглашению |
| `leave_chat` | удаление | выход из группы или канала, удаление личного чата |
| `delete_messages` | удаление | удаление сообщений |
| `manage_chat` | администрирование | участники, админы, название, описание, фото, медленный режим, ссылки, заявки |
| `create_chat` | администрирование | новая группа или канал |
| `update_profile` | профиль | имя, био, @username, фото |
| `manage_contact` | профиль | добавить, удалить, заблокировать, разблокировать |
| `search_api_methods` | прямые вызовы | поиск методов и типов API по названию |
| `describe_api_method` | прямые вызовы | параметры метода, конструкторы типа |
| `send_api_request` | прямые вызовы | вызов любого метода API |

Чат можно указать как угодно: id из ответов коннектора, `@username`, ссылкой `t.me/…` (в том числе на конкретное сообщение, тему форума, приглашение или `?start=`), `me` для «Избранного» или точным названием из списка чатов.

Тексты сообщений приходят в Markdown: `**жирный**`, `*курсив*`, `__подчёркнутый__`, `~~зачёркнутый~~`, `||спойлер||`, `` `код` ``, `[текст](ссылка)`, строки `> цитаты`. Так же Claude и пишет — коннектор превращает разметку в форматирование Telegram.

## Примеры

- «Что нового в Telegram? Покажи непрочитанное и кратко перескажи».
- «Найди канал про архитектуру ПО и вступи в него».
- «Открой бота @some_bot, нажми „Каталог“ и расскажи, что там есть».
- «Ответь Ивану на последнее сообщение: созвонимся в пятницу в 11».
- «Найди в чате „Работа“ сообщения про отчёт за август».
- «Что на фото в последнем сообщении от Маши?»
- «Расшифруй голосовые от Маши за сегодня и кратко перескажи».
- «Отправь в „Избранное“ файл ~/Desktop/plan.pdf с подписью „план на квартал“».
- «С рабочего аккаунта: какие чаты с упоминаниями меня?»

## Подключение без пакета

Сервер можно прописать вручную — в `~/Library/Application Support/Claude/claude_desktop_config.json` (Claude Desktop) или командой `claude mcp add` (Claude Code). Учтите, что API Hash в таком конфиге лежит открытым текстом.

```json
{
  "mcpServers": {
    "telegram": {
      "command": "node",
      "args": ["/путь/к/telegram-mcp/server/index.js", "--upload-dirs", "/Users/me/Downloads", "/Users/me/Desktop"],
      "env": {
        "TELEGRAM_API_ID": "123456",
        "TELEGRAM_API_HASH": "…"
      }
    }
  }
}
```

```bash
claude mcp add telegram -e TELEGRAM_API_ID=123456 -e TELEGRAM_API_HASH=… -- node /путь/к/telegram-mcp/server/index.js --upload-dirs ~/Downloads
```

Перед этим выполните `npm ci` в папке проекта.

### Переменные окружения

| Переменная | По умолчанию | |
|---|---|---|
| `TELEGRAM_API_ID`, `TELEGRAM_API_HASH` | — | с my.telegram.org |
| `TELEGRAM_DEFAULT_ACCOUNT` | — | аккаунт по умолчанию |
| `TELEGRAM_ALLOW_SEND`, `…_BOTS`, `…_JOIN` | `true` | разрешения |
| `TELEGRAM_ALLOW_DELETE`, `…_ADMIN`, `…_PROFILE`, `…_RAW_API` | `false` | разрешения |
| `TELEGRAM_VISIBLE_CHATS`, `TELEGRAM_HIDDEN_CHATS`, `TELEGRAM_WRITABLE_CHATS` | — | списки чатов через запятую |
| `TELEGRAM_READ_ONLY_ACCOUNTS` | — | аккаунты только для чтения |
| `--upload-dirs …` или `TELEGRAM_UPLOAD_DIRS` | — | папки для отправки (в переменной — через `:`, в Windows через `;`) |
| `TELEGRAM_DOWNLOAD_DIR` | `~/Downloads` | куда сохранять файлы |
| `TELEGRAM_ACTIONS_PER_MINUTE` | `20` | лимит действий на аккаунт |
| `TELEGRAM_PROXY` | — | SOCKS5, SOCKS4 или MTProxy |
| `TELEGRAM_TRANSCRIBE_API_KEY` | — | ключ сервиса расшифровки голосовых (Groq, OpenAI) |
| `TELEGRAM_TRANSCRIBE_API_URL`, `TELEGRAM_TRANSCRIBE_MODEL` | по ключу | адрес API (…/v1) и модель расшифровки |
| `TELEGRAM_DATA_DIR` | `~/.telegram-mcp` | папка с сессиями |
| `TELEGRAM_MAX_DOWNLOAD_MB` | `500` | предел размера скачиваемого файла |
| `TELEGRAM_MAX_OUTPUT_CHARS` | `60000` | предел длины ответа инструмента |
| `TELEGRAM_CALL_BUDGET_MS` | `45000` | сколько ждать долгие операции, прежде чем продолжить их в фоне |
| `TELEGRAM_LOG_LEVEL` | `info` | `error`, `warn`, `info`, `debug` (журнал — в stderr) |
| `TELEGRAM_TEST_SERVERS` | `false` | тестовые серверы Telegram (для разработки) |
| `TELEGRAM_ALLOW_SERVICE_CHAT` | `false` | показывать служебный чат 777000 — не включайте без крайней нужды |

## Ограничения

- **Секретные чаты** недоступны: их ключи есть только на ваших устройствах.
- **Звонки, мини-приложения, платежи** — нет. Истории — только через прямые вызовы API.
- **Вложения из чата с Claude** (картинка, которую вы перетащили в Claude) коннектор отправить не может — только файлы с диска из разрешённых папок, ссылки и небольшие файлы, которые Claude создаёт сам (`data_base64`).
- **Большие файлы** скачиваются и отправляются в фоне, если не успевают за ~45 секунд: Claude сообщит, где проверить результат.
- **reCAPTCHA.** Иногда Telegram требует проверку при входе по номеру — тогда входите по QR-коду.
- Один и тот же аккаунт можно одновременно использовать в Claude Desktop и Claude Code, но лучше не запускать вход в него из двух мест сразу.

## Разработка

```bash
npm test             # тесты (node:test, поддельный клиент Telegram)
npm run validate     # проверка manifest.json
npm run pack         # сборка dist/telegram.mcpb
npm run check-pack   # запуск сервера из собранного пакета
npm run icon         # перерисовать icon.png
```

Устройство:

- `server/index.js` — точка входа, инструкции для модели; `server/mcp.js` — MCP поверх stdio (JSON-RPC, без SDK, как в коннекторе Bybit), обе эпохи протокола: современная 2026-07-28 (`server/discover`, её сначала пробует Claude Desktop) и прежняя с `initialize` (2025-11-25 и раньше). Совместимость проверена официальным клиентом `@modelcontextprotocol/client` 2.0.0 в режимах `legacy`, `auto` и `{ pin: '2026-07-28' }`;
- `server/config.js` — настройки из окружения; `server/policy.js` — разрешения, списки чатов, файлы, лимит;
- `server/accounts.js`, `server/store.js` — аккаунты, сессии и кэш сущностей;
- `server/login/` — вход (сценарий, локальная страница, QR); `server/cli.js` — вход из терминала;
- `server/tg/` — teleproto, ссылки на чаты, форматирование, Markdown, схема API;
- `server/tools/` — инструменты по группам.

Для ручной проверки без настоящего аккаунта есть тестовые серверы Telegram: `TELEGRAM_TEST_SERVERS=true`, номер вида `99966XYYYY` (X — номер дата-центра 1–3), код — цифра X пять раз. API ID и API Hash нужны настоящие.

## Зависимости

- [teleproto](https://github.com/sanyok12345/teleproto) 1.229.0 (MIT) — клиент MTProto, продолжение GramJS (сам GramJS архивирован в июле 2026 года). Версия в названии соответствует слою API Telegram (229).
- [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator) (MIT) — QR-код для входа.

Расшифровка голосовых обходится без библиотек: запрос к API встроенным в Node.js `fetch`.
